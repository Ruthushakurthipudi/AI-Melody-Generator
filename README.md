## 📌 Project Overview

AI Melody Generator is an Artificial Intelligence project
that generates new musical melodies using a Long Short-Term
Memory (LSTM) neural network.

The model learns patterns from MIDI music data and
generates new musical sequences that can be saved as
MIDI files.

## 🎯 Objectives

- Generate music using Artificial Intelligence.
- Learn musical patterns using an LSTM model.
- Process MIDI music data.
- Generate new musical note sequences.
- Save generated music as MIDI and WAV audio files.

## 🛠️ Technologies Used

- Python
- Google Colab
- TensorFlow
- LSTM Neural Network
- Music21
- NumPy
- Matplotlib
- MIDI

## 🔄 Project Workflow

1. Collect MIDI music data.
2. Extract notes and chords from MIDI files.
3. Convert musical notes into numerical sequences.
4. Prepare training data.
5. Build an LSTM neural network.
6. Train the model on musical sequences.
7. Generate new musical notes.
8. Convert the notes into a MIDI file.
9. Convert the MIDI file into WAV audio.
10. Play and save the generated music.

## 🧠 Model Used

### Long Short-Term Memory (LSTM)

LSTM is a type of recurrent neural network that can learn
patterns in sequential data.

In this project, the LSTM model learns musical note patterns
and predicts the next note in a sequence.

